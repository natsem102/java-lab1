## Задача 8
### Текст задачи
**Возраст.**
Дана сигнатура метода: `public String age (int x);`
Необходимо реализовать метод таким образом, чтобы он возвращал строку, в которой сначала будет число х, а затем одно из слов:
год
года
лет
Слово “год” добавляется, если число х заканчивается на 1, кроме числа 11.
Слово “года” добавляется, если число х заканчивается на 2, 3 или 4, кроме чисел 12, 13, 14.
Слово “лет” добавляется во всех остальных случаях.
Подсказка: оператор % позволяет получить остаток от деления.

Пример 1:

Пример 2:

Пример 3:
x=44
результат: “44 года”
### Алгоритм решения
Определяются последняя цифра `d = x % 10` и две последние цифры `t = x % 100`. Если `d == 1` и `t != 11` — добавляется «год». Если `d` от 2 до 4 и `t` не входит в диапазон 12–14 — добавляется «года». Во всех остальных случаях — «лет». Проверка по двум последним цифрам (`t`) также корректно обрабатывает числа вроде 111, 112 («лет»). При вводе допускается возраст от 0 до 1000.

## Задача 10
### Текст задачи
**Вывод дней недели.**
Дана сигнатура метода: `public void printDays (String x);`
В качестве параметра метод принимает строку, в которой записано название дня недели. Необходимо реализовать метод таким образом, чтобы он выводил на экран название переданного в него дня и всех последующих до конца недели дней. Если в качестве строки передан не день, то выводится текст “это не день недели”. Первый день понедельник, последний – воскресенье. Вместо if в данной задаче используйте switch.

Пример 1:
x=”четверг”
результат:
```
четверг
пятница
суббота
воскресенье
```

Пример 2:
x=”чг”
результат:
```
это не день недели
```
### Алгоритм решения
Используется `switch` по строке. Ветки `case` перечислены в порядке следования дней, от понедельника до воскресенья, и в каждой ветке день выводится на экран. Оператор `break` в ветках дней не ставится, поэтому после совпадения выполнение «проваливается» в следующие ветки и выводятся все последующие дни. `break` стоит только после воскресенья, чтобы не перейти в `default`. В ветке `default` выводится «это не день недели». Введённая строка перед вызовом приводится к нижнему регистру и очищается от пробелов по краям.

**Все вхождения.**
Дана сигнатура метода: `public int[] findAll (int[] arr, int x);`
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, в котором записаны индексы всех вхождений числа x в массив arr.
